# Cyber City, Samastipur — स्टैटिक वेबसाइट (20 पेज + 404)

HTML5 + CSS3 + Vanilla JS। कोई बैकएंड/डेटाबेस नहीं, इसलिए GitHub Pages पर चलती है। इसमें कोई पासवर्ड, API key या secret नहीं है।

## 1. दुकान की जानकारी भरें (ज़रूरी)
`assets/js/config.js` खोलें और भरें: `phone`, `whatsapp` (देश कोड सहित, जैसे `919XXXXXXXXX`), `email`, `address`, `hours`, `mapEmbed`, `social`.
खाली छोड़ने पर साइट "जल्द उपलब्ध" दिखाती है — कोई नंबर/पता बनाया नहीं गया है।

## 2. सेवाएँ, कीमतें व अपडेट
- `data/services.json` — हर सेवा का `charge` भरें (जैसे `"₹50 से शुरू"`). खाली हो तो "शुल्क: दुकान से पूछें" दिखता है।
- `data/updates.json` — नौकरी/एडमिट कार्ड/रिज़ल्ट आदि की सूचनाएँ हाथ से जोड़ें। अभी की प्रविष्टियाँ `"sample": true` हैं ("नमूना" बैज दिखता है); असली सूचना जोड़ने पर इसे हटा दें। केवल सत्यापित, आधिकारिक `https://` लिंक डालें।
- टेक्स्ट बदलने के बाद पेज दोबारा बनाएँ (Python 3 चाहिए):

      python3 tools/build.py --url https://USERNAME.github.io/REPO-NAME/

  यह सभी HTML, `sitemap.xml`, `robots.txt` (canonical URL सहित) बनाता है। `--url` ज़रूर दें।

## 3. GitHub Pages पर डालना
1. github.com पर नया repository बनाएँ (जैसे `cyber-city`)।
2. इस फोल्डर की सारी फाइलें अपलोड करें (Add file → Upload files) और Commit करें।
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save।
4. 1–2 मिनट बाद `https://USERNAME.github.io/cyber-city/` पर साइट खुलेगी। HTTPS अपने आप चालू रहता है।
5. अपना डोमेन हो तो Pages में Custom domain जोड़ें और `--url` से दोबारा build करें।
6. Google Search Console में `sitemap.xml` जमा करें।

स्थानीय जाँच: फोल्डर में `python3 -m http.server 8000` चलाकर `http://localhost:8000` खोलें। (सीधे फाइल खोलने पर अपडेट सूची लोड नहीं होगी क्योंकि ब्राउज़र `fetch` रोकता है।)

## 4. क्या काम करता है
- सभी 20 पेज + `404.html`, स्टिकी मेन्यू, मोबाइल हैम्बर्गर, ड्रॉपडाउन, breadcrumb, फुटर में सभी लिंक।
- सेवा खोज: होम पेज से `services.html?q=…`; `services.html` पर लाइव फ़िल्टर व श्रेणी बटन; हर सेवा का विवरण `services.html?s=<id>`।
- हर पेज पर unique title/description, canonical, Open Graph।
- संपर्क फॉर्म: सर्वर-रहित है। वैधता जाँच के बाद (सहमति सहित) WhatsApp खोलता है, या `config.js` में `formEndpoint` (जैसे Formspree) दें तो वहाँ भेजता है। OTP/पासवर्ड/12 अंकों की संख्या वाले संदेश रोके जाते हैं। कोई डेटा साइट पर संग्रहीत नहीं होता।
- "English" बटन केवल मेन्यू का नाम बदलता है; पूरा द्विभाषी अनुवाद अभी नहीं है।

## 5. जो जानबूझकर नहीं किया
- कोई नकली समीक्षा, रेटिंग, लाइव सूचना, आवेदन स्थिति या सरकारी संबद्धता नहीं।
- सुरक्षित Admin Panel/लॉगिन नहीं — GitHub Pages पर यह संभव नहीं। भविष्य में PHP/MySQL (प्रमाणीकरण व सर्वर-साइड validation के साथ) से जोड़ें: admin dashboard, सेवा ट्रैकिंग, बुकिंग, कीमत प्रबंधन, WhatsApp Business, रसीद/इनवॉइस।
- `LocalBusiness` structured data जोड़ें केवल तब जब नाम, पता, फ़ोन सत्यापित हों (हर पेज के `<head>` में, `tools/build.py` के `head()` में)।
- Logo इनलाइन SVG है; फोटो/इमेज नहीं, इसलिए साइट तेज़ है। अपनी दुकान की फोटो जोड़ें तो `loading="lazy"` और WebP उपयोग करें।

## 6. प्रकाशन से पहले जाँचें
- आधिकारिक बाहरी लिंक (विशेषकर बिहार पोर्टल, बोर्ड/विश्वविद्यालय) एक बार खुलकर देख लें — सरकारी साइटें पते बदलती रहती हैं।
- गोपनीयता नीति व नियम/रिफंड पेज सामान्य मसौदे हैं; अपनी दुकान के अनुसार अंतिम करें।
- आधार/PAN जैसी सेवाओं की अधिकृतता का दावा तभी लिखें जब आपके पास प्रमाण हो।
